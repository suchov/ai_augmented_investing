# Decision Journal — зовнішній мозок для value investing

Система з трьох файлів + інтерв'ю-режим для Claude CLI.
Розрахована на AuDHD-профіль: zero blank pages, zero щоденної дисципліни,
кожен запис самодостатній, ініціація через діалог.

## Структура

```
journal/
├── inbox.md                     # захоплення ідей, 15 секунд на запис
├── decisions.md                 # журнал рішень (buy / sell / pass)
├── watchlist/
│   ├── _TEMPLATE.md             # шаблон для нового тікера
│   └── PGR.md                   # приклад заповненого файлу
└── .claude/skills/journal/
    └── SKILL.md                 # інтерв'ю-режим для Claude Code
```

## Workflow

1. **Захоплення.** Побачив тікер → один рядок в `inbox.md`. Без оцінки.
   Правило 30 секунд: не записав одразу — ідеї не існує.

2. **Тріаж (коли є hyperfocus-вікно).** Запускаєш `claude` в корені репо і кажеш
   `розбери inbox` — Claude проходить по рядках, ставить питання по кожному,
   і або створює `watchlist/TICKER.md`, або пише pass-запис у `decisions.md`,
   або лишає в inbox з позначкою `later`.

3. **Рішення.** Купуєш / продаєш / свідомо відмовляєшся → кажеш Claude
   `журнал: рішення по TICKER` — він інтерв'ює тебе і пише запис у `decisions.md`.

4. **Review без сили волі.** Кожен watchlist-файл має `next_catalyst` з датою →
   постав календарну подію з текстом "відкрий watchlist/TICKER.md".
   Тригер зовнішній, прив'язаний до конкретного файлу.
   Квартальний calibration-проход — якір: вихід листа Semper Augustus.

## Ключові правила

- **Pass log — найцінніша частина.** Кожна відмова записується з причиною
  і умовою повернення (`revisit_if`). Це захист від повторного дослідження
  того самого тікера через 4 місяці.
- **Один активний домен.** Файли не вимагають підтримки. Якщо інвестування
  запарковане на місяць — система нічого не втрачає, все лежить у файлах.
- **Claude читає журнал сам.** При аналізі нової ідеї в pipeline Claude
  спочатку грепає decisions.md і watchlist/ — і каже, якщо ти це вже дивився.

## Інтеграція в ai_augmented_investing

Скопіюй вміст цієї папки в корінь репо (або в підпапку `journal/`,
тоді онови шляхи в SKILL.md). Skill підхопиться автоматично,
якщо `.claude/skills/journal/SKILL.md` лежить у корені проєкту.
